About CyberEnsō

You might be wondering what is an Ensō! Ensō is a Zen-buddhist practice that allows one to create a momentous artwork. To know more you can visit the Wikipedia Page.

CyberEnsō is my take on traditional Ensō. It is a simple web app to create an momentous Ensō. We take the content from the textarea and hash it. Hashing is a destructive process and I'm using it as an analog of clearing one's mind for painting an Ensō.
